% Abstract

\begin{abstract}
Ant Colony Optimization (ACO) often stagnates when pheromone values concentrate on suboptimal edges. While neural-guided variants learn instance-conditioned priors, they typically compute guidance only once before search begins.
Learning-Guided ACO (\LGA{}) instead employs a closed-loop controller that periodically observes the current pheromone distribution and incumbent solution, emitting per-edge residual logits that remain fixed for a block of $S=100$ inner iterations before being refreshed.
The shaped transition kernel corresponds to exponential tilting of the baseline ACO policy.
We find that localized local search---without neural guidance during the LS phase---suffices for stable policy-gradient training: by preserving $\approx 30\%$ of sampled edges, it maintains credit assignment between the controller's decisions and the post-LS tour quality.
We show that spatial locality alone substitutes for the neural-guided LS used in prior work.
Experiments on Euclidean \TSP{} and \CVRP{} demonstrate that \LGA{} outperforms both vanilla perturbation-based ACO and open-loop neural guidance under matched wall-clock budgets.
\end{abstract}

\section{Introduction}

Ant Colony Optimization (ACO) has proven effective for routing problems, but stagnation remains a persistent problem: once pheromone values concentrate on a suboptimal tour, exploration effectively ceases and quality plateaus.
Standard countermeasures such as periodic restarts or pheromone smoothing help, but they ignore the actual state of the search.
Recent neural ACO variants, including DeepACO~\cite{deepaco}, learn instance-conditioned guidance that improved solution quality. This guidance, however, remains static: it is computed once before search begins, leaving the solver unable to react when pheromones converge prematurely or when improvements stall.

We propose Learning-Guided ACO (\LGA{}), a closed-loop neural controller that periodically examines the current pheromone distribution and incumbent tour, then emits per-edge residual logits that are held constant for $S$ inner iterations before being refreshed.
The controller sees the search evolution and steers sampling toward edges that look promising given the current trajectory, rather than relying solely on static instance geometry (\Cref{sec:controller}).

The underlying optimization framework is a perturbation-based ACO~\cite{faco} that restricts each ant to a bounded number of relocation steps, producing focused large-neighborhood exploration.
Crucially, we employ a localized local search (LS) rather than global 2-opt.
As we discuss in \Cref{sec:localized-ls}, localized LS limits structural modifications to the neighborhood of an ant's actions, preserving the action--outcome link necessary for stable policy-gradient training.

Open-loop neural ACO methods compute guidance $g_\theta(\cdot; x)$ once and never revisit it; \LGA{} recomputes $g_\theta(\cdot; \mathcal{S}_h)$ at each of $H$ refresh points, conditioning on the evolving solver state $\mathcal{S}_h$.

The principal contributions of this work are as follows.
(1)~We introduce a closed-loop neural ACO controller that conditions on pheromone state and incumbent structure, refreshing guidance periodically (\Cref{sec:method}).
(2)~We identify localized local search as a key stabilizer for policy-gradient training, using edge survival to diagnose its role in maintaining credit assignment (\Cref{sec:localized-ls}).
(3)~We extend the framework to CVRP via a giant-tour representation (\Cref{sec:cvrp}).
(4)~Experiments on TSP and CVRP show that \LGA{} consistently improves over vanilla ACO under matched wall-clock budgets, with the largest gains observed on smaller, structured instances (\Cref{sec:experiments}).

\section{Related Work}
\subsection{Neural Combinatorial Optimization}
Neural Combinatorial Optimization (NCO) applies deep learning to NP-hard routing problems~\cite{MLCO}.
End-to-end methods generate solutions directly via attention-based decoding~\cite{pointernetwork,kool2019attention,kwon2020pomo}, while Learning-Guided Optimization (LGO) produces edge-level heuristics that guide a classical solver~\cite{RL4CO}. This latter approach combines learned representations with principled search mechanisms.

\subsection{Neural-Guided Ant Colony Optimization}
Several works augment ACO with learned priors.
DeepACO~\cite{deepaco} trains a GNN to output edge logits replacing or augmenting the heuristic $\eta_{ij}$.
Similarly, GFACS~\cite{gfacs} uses Generative Flow Networks, and GTG-ACO~\cite{gtgaco} uses Graph Transformers.
Unlike our method, these approaches are open-loop: they compute guidance once before search and do not adapt to evolving search dynamics.

\subsection{Perturbation-Based ACO}
Another line of research improves ACO scalability by re-using and partially modifying elite solutions, effectively making ACO behave like large-neighborhood search (LNS).
Focused ACO~\cite{faco} bounds differences between a newly constructed solution and the incumbent, yielding focused search with tighter LS coupling.
We investigate whether a neural controller can further improve this family by reacting to solver state.

\subsection{Learning to Control Optimization}
Our work draws on learning to optimize~\cite{bengio2021machine}, where neural networks parameterize components of optimization algorithms (e.g., branch-and-bound policies~\cite{gasse2019exact}, adaptive operator selection~\cite{li2019learning}).
We implement closed-loop feedback control: the controller observes pheromones and the incumbent, then modulates transitions accordingly.

\subsection{Adaptive and Parameter-Control ACO}
Adapting ACO parameters during search has a long history.
\emph{Adaptive} or \emph{self-adaptive} ACO variants dynamically adjust evaporation rates, pheromone bounds, or exploration parameters based on search progress~\cite{stutzle2000max,pellegrini2012ant}.
These typically use hand-crafted rules (e.g., restart after stagnation, increase $\rho$ when diversity is low).
Our adaptation rule is instead \emph{learned} from data and conditions on richer state representations (pheromone distribution, incumbent structure) rather than scalar metrics.

\subsection{Learning-Guided Large Neighborhood Search}
Neural networks have been used to guide operator selection in Large Neighborhood Search (LNS)~\cite{hottung2019neural,chen2019learning}.
These methods learn which destroy/repair operators to apply at each iteration, framing operator selection as a contextual bandit or RL problem.
Our work operates at a different level: rather than selecting operators, we directly shape transition probabilities within a fixed operator (perturbative ACO sampling).
This gives finer-grained control but requires differentiable integration with sampling.

\subsection{Pheromone and State Features for Learned Guidance}
Prior work has explored pheromone information as features for learning.
RLAnt~\cite{rlant} uses RL to tune ACO parameters based on convergence metrics.
Some works use pheromone-derived features for quality prediction or algorithm selection~\cite{smith-miles2014landscape}.
To our knowledge, no prior work conditions a neural network directly on the full pheromone matrix (or local statistics) to produce per-edge guidance.

\section{Background and Preliminaries}
\label{sec:background}

\subsection{Problem Definitions}
We consider Euclidean \TSP{} on a graph $G=(V, E)$ with $n = |V|$ nodes.
The goal is to find a Hamiltonian cycle $\pi$ minimizing tour length:
\begin{equation}
C(\pi) = \sum_{i=1}^{n-1} d(\pi_i, \pi_{i+1}) + d(\pi_n, \pi_1),
\end{equation}
where $d(\cdot, \cdot)$ denotes Euclidean distance.
For \CVRP{}, we add a depot (node~0) and vehicle capacity $Q$.
The objective is to find routes---each starting and ending at the depot---that collectively visit all customers within capacity limits.
We generate random instances with coordinates sampled uniformly from $[0, 1]^2$.

To scale to large instances we solve on a sparse $K$-nearest-neighbor candidate graph rather than the complete graph, restricting tours to edges in this candidate set---a standard choice in scalable \TSP{}/\CVRP{} heuristics~\cite{helsgaun2000effective}.
Throughout, we set $K=32$.

\subsection{Ant Colony Optimization}
\label{sec:aco}
We adopt the standard ACO transition rule (Eq.~\ref{eq:aco-transition}), but modify the probability mass to incorporate learned residuals.
At each step, an ant at node $i$ chooses the next node $j$ from its feasible neighborhood $\mathcal{N}(i)$:
\begin{equation}
p(j \mid i) = \frac{[\tau_{ij}]^\alpha [\eta_{ij}]^\beta}{\sum_{k \in \mathcal{N}(i)} [\tau_{ik}]^\alpha [\eta_{ik}]^\beta}, \quad j \in \mathcal{N}(i).
\label{eq:aco-transition}
\end{equation}
Here, $\tau_{ij}$ denotes trail intensity and $\eta_{ij}$ heuristic visibility.

\subsection{\MMAS{} and Stagnation}
\emph{Max-Min Ant System} (\MMAS{})~\cite{stutzle2000max} improves standard ACO by bounding pheromone values to $\tau_{ij} \in [\tau_{\min}, \tau_{\max}]$, preventing premature convergence.
Only the iteration-best or global-best ant deposits pheromone, focusing reinforcement on high-quality solutions.
Despite these mechanisms, \emph{stagnation}---$\tau$ converging to a suboptimal tour while exploration ceases---remains a core challenge.

\subsection{Local Search}
Competitive performance requires integrating local search (LS) into ACO.
For \TSP{}, 2-opt moves are standard.
LS improves solution quality but complicates learning by decoupling the policy's edge choices from the final reward---we address this via localized LS (\Cref{sec:localized-ls}).

\section{Method}
\label{sec:method}

This section describes \LGA{}, a closed-loop neural controller for ACO.
We give an overview (\Cref{sec:overview}), then detail controller parameterization (\Cref{sec:state,sec:controller,sec:architecture}), training (\Cref{sec:training}), and pheromone stabilization (\Cref{sec:smoothed-mmas}).

\subsection{Overview}
\label{sec:overview}

We run a perturbation-based ACO backend~\cite{faco} on a sparse $K$-nearest-neighbor candidate graph.
Every $S$ inner iterations---one \emph{outer step} $h$---the controller observes the macro-state $\mathcal{S}_h = (x, \tau^{(h,0)}, b^{(h)})$, comprising the instance $x$, the pheromone matrix at the start of the outer step, and the current incumbent tour $b$.
From this state it computes shaping logits $z_\theta(\mathcal{S}_h) \in \R^{n \times K}$, which are then held constant while $S$ inner iterations execute: ants sample tours via perturbation-based construction (at most $M$ relocation steps from the incumbent), localized LS is applied, and pheromones and the incumbent are updated.
The total iteration count is therefore $T = H \cdot S$, where $H$ is the number of outer steps.
Because pheromones change at every inner iteration, we write $\tau^{(h)}$ for the pheromone state at the \emph{start} of outer step $h$.

Importantly, the controller only reweights candidate edges; it cannot eliminate any of them.
It operates strictly within the candidate graph and the bounded-perturbation constraints inherited from the backend, which handles pheromone updates, incumbent tracking, and localized LS.

Ants do not construct tours from scratch.
Following~\cite{faco}, each ant starts from a copy of the incumbent tour $b^{(h)}$ and performs a constrained rewire (see also Algorithm~\ref{alg:perturbation}).
A random starting node $u_0$ is selected and marked visited.
The ant then repeatedly samples a next node $v$ from the unvisited neighbors of the current node $u$ according to Eq.~\eqref{eq:held-logits}; whenever the chosen edge $(u,v)$ does not belong to the incumbent, we track the set of edges modified by the perturbation to constrain the subsequent local search scope.
Node $v$ is then \emph{relocated}: it is removed from its current position in the tour and inserted immediately after $u$, an operation that changes up to three tour edges while maintaining feasibility.
The walk continues until either $M$ such ``new-edge'' steps have been taken or a fixed budget is exhausted, at which point the modified tour is returned.

$M$ controls the number of \emph{relocation steps where the sampled edge $(u,v)$ was not in the incumbent}.
Each relocation can modify up to 3 tour edges (removing 2, adding 2, with one shared), so the edge-set symmetric difference can exceed $M$.
But the perturbation remains localized: ants make at most $M$ exploratory steps introducing new connectivity, focusing search around the current best region.

The action space is a sequence of \emph{next-node choices} from the candidate graph, as in classical ACO but constrained to terminate early.
The log-probability of a sampled tour sums over stochastic node selections:
\begin{equation}
\log \pi_\theta(\pi_{a,s} \mid \mathcal{S}_h) = \sum_{t=1}^{T_a} \log p^\theta(v_t \mid u_t; h, s),
\label{eq:logp-trajectory}
\end{equation}
where $T_a \le M$ is the number of steps taken by ant $a$, and we sum only over stochastic decisions (steps with $>1$ feasible candidate).

Throughout, $h = 1,\ldots,H$ indexes outer steps (controller refreshes) and $s = 1,\ldots,S$ indexes inner ACO iterations within each outer step.
We write $b^{(h)}$ for the incumbent at outer step $h$ and $\tau^{(h,s)}$ for the pheromone matrix at inner iteration $s$ of that step.

The neural controller emits shaping logits $z_\theta(\mathcal{S}_h)$ once at the start of each outer step and then holds them constant for all $S$ inner iterations that follow.
Pheromones, however, continue to evolve at every inner iteration via standard \MMAS{} updates.
At inner iteration $s$ the transition kernel combines the \emph{current} pheromones $\tau^{(h,s)}$ with the \emph{held} neural logits $z_\theta(\mathcal{S}_h)$:
\begin{equation}
\log p^\theta(j \mid i; h, s) = \alpha \log \tau^{(h,s)}_{ij} + \beta \log \eta_{ij} + z_{ij}(\mathcal{S}_h) - \log Z_i.
\label{eq:held-logits}
\end{equation}
This design decouples the pheromone dynamics, which update at every inner step, from the neural control signal, which updates only at outer-step boundaries.

\subsection{Sample-and-Hold Control}
\label{sec:process}
The controller is invoked every $S$ inner steps.
At outer step $h$, it observes $\mathcal{S}_h = (x, \tau^{(h,0)}, b^{(h)})$ and outputs shaping logits $z_\theta(\mathcal{S}_h) \in \R^{n\times K}$, held constant for $S$ iterations.

Refreshing every iteration is expensive and potentially unstable; refreshing too rarely reduces the system to an open-loop controller.
Sample-and-hold trades off compute and adaptivity: inference cost is amortized over $S$ sampling steps while still adapting as search progresses.
We ablate the $(H, S)$ factorization in \Cref{sec:ablations}.


\subsection{State Representation}
\label{sec:state}
The controller conditions on search context $\mathcal{S}_h$, capturing both static instance structure and dynamic search state.

On the static side, a GNN encoder computes node embeddings $h_i \in \R^d$ from node coordinates and the $K$-NN distance graph.
Dynamic features are attached to each candidate edge $(i, j)$: the relative pheromone $\log(\tau_{ij} / \bar{\tau}_i)$, where $\bar{\tau}_i$ is the mean pheromone over candidates of node $i$; the coefficient of variation of pheromone values at node $i$, capturing local dispersion; and binary indicators of whether edge $(i,j)$ belongs to the current incumbent tour (see the Appendix for details).

\subsection{Log-Space Shaping}
\label{sec:controller}
The controller outputs a scalar guidance score $z_{ij} = g_{\theta}(i, j; \mathcal{S}_h)$ for each candidate edge, held constant for all inner steps $s = 1, \ldots, S$.
At inner step $s$, the baseline ACO distribution (without neural guidance) is:
\begin{equation}
q^{(h,s)}(j \mid i) \propto [\tau^{(h,s)}_{ij}]^\alpha [\eta_{ij}]^\beta.
\label{eq:baseline-aco}
\end{equation}
The shaped transition kernel adds the learned logits in log-space:
\begin{equation}
\log p^\theta(j \mid i; h, s) = \alpha \log \tau^{(h,s)}_{ij} + \beta \log \eta_{ij} + z_{ij}(\mathcal{S}_h) - \log Z_i,
\label{eq:logspace-prior}
\end{equation}
where $Z_i$ is the partition function.
Note that both $q^{(h,s)}$ and $p^\theta(\cdot; h, s)$ depend on the evolving pheromones $\tau^{(h,s)}$, but only $p^\theta$ includes the held neural logits $z(\mathcal{S}_h)$.

This additive log-space formulation corresponds to a KL-regularized policy, where the controller tilts the baseline ACO probability $q^{(h,s)}$:
\begin{equation}
p^\theta(\cdot\mid i; h,s) \propto q^{(h,s)}(j\mid i)\exp(z_{ij}).
\end{equation}
Because $\tau_{\min} > 0$, $\eta_{ij} > 0$, and the neural logits $z_{ij}$ remain finite, every candidate edge retains strictly positive probability under $p^\theta$.
The controller can therefore redistribute probability mass among candidates but cannot exclude any of them outright.

\subsection{Architecture}
\label{sec:architecture}
The controller consists of an encoder---a 12-layer GNN with residual connections and batch normalization that produces edge embeddings $w_{ij} \in \mathbb{R}^{32}$ from node coordinates and edge features---followed by a decoder, a 3-layer MLP that maps these embeddings to scalar guidance logits $g_{\theta}(i, j)$.

Because the GNN encoder runs only once per outer step rather than at every inner iteration, its cost is amortized over $S$ sampling steps.
The encoder receives both static features (node coordinates, candidate distances) and dynamic features (pheromone state, incumbent structure); because the latter change only at outer-step boundaries, recomputation within an outer step is unnecessary.
Asymptotically, the GNN forward pass costs $O(L \cdot n \cdot K \cdot d)$ for $L$ layers, $n$ nodes, $K$ candidates, and hidden dimension $d=32$, and it runs $H$ times per instance.
This yields a total neural cost of $O(H \cdot L \cdot n \cdot K \cdot d)$, compared with $O(T \cdot m \cdot M \cdot K)$ for sampling ($T = H \cdot S$, $m$ ants, $M$ perturbations per ant).
Under the default settings ($H=10$, $S=100$, $m=100$, $M=12$), neural overhead accounts for roughly 5--15\% of total runtime at $n=10$K (Table~\ref{tab:profiling}).

% 4.1 Smoothed MMAS
% ======================================================================
\subsection{Stabilized Pheromone Dynamics}
\label{sec:smoothed-mmas}
Standard \MMAS{} dynamically adjusts pheromone bounds based on best tour cost, coupling dynamics to objective scaling.
This introduces instability when training neural controllers: the input distribution (pheromone values) varies with instance difficulty.

To address this, we adopt fixed bounds ($\tau_{\max}=1$, $\tau_{\min}=1/K$) that do not depend on instance cost.
Let $B$ denote the edge set of the best solution (iteration-best or global-best).
We update each pheromone value via convex interpolation toward a fixed target:
\begin{equation}
\tau^{(h,s+1)}_{ij} \leftarrow (1-\rho)\tau^{(h,s)}_{ij} + \rho \cdot \mathcal{T}_{ij},
\label{eq:smoothed-mmas}
\end{equation}
where $\mathcal{T}_{ij} = \tau_{\max}$ if $(i,j) \in B$ and $\mathcal{T}_{ij} = \tau_{\min}$ otherwise.

$\tau_{\min} = 1/K$ follows the \MMAS{} principle that even under maximum pheromone concentration, non-best edges retain non-negligible selection probability.
In a simplified setting with uniform heuristic ($\eta_{ij} = 1$) and no neural prior ($z_{ij} = 0$), with $K$ candidates per node and pheromones at extremes, minimum selection probability is approximately $\tau_{\min} / (\tau_{\max} + (K-1)\tau_{\min})$.
Setting $\tau_{\min} = \tau_{\max}/K = 1/K$ gives a probability floor of $\approx 1/(2K-1) \approx 1.6\%$ for $K=32$.

The full transition kernel includes $\eta_{ij}^\beta$ and neural logits $z_{ij}$, which can further concentrate or disperse probability mass.
The $1/(2K-1)$ figure is \emph{not} a hard guarantee but an intuition about the pheromone-induced diversity floor in isolation.
The neural controller can learn to counteract excessive concentration by adjusting logits, and $\eta^\beta$ is fixed per instance.
The goal is to prevent pheromones \emph{alone} from collapsing to a deterministic policy, leaving room for learned adaptation.

A practical benefit is that fixed bounds yield scale-stable inputs: the controller sees pheromone values in the same range regardless of instance difficulty.
The update rule~\eqref{eq:smoothed-mmas} is a contraction: pheromones stay in $[\tau_{\min}, \tau_{\max}]$ regardless of best-set sequence, preventing unbounded growth or collapse under cost-calibrated bounds.
This stabilizes training without sacrificing solution quality (Section~\ref{sec:ablations}).

The evaporation rate $\rho$ governs how quickly pheromones track changes in the best solution: larger values speed convergence but also cause faster forgetting of exploration history.
We set $\rho=0.1$ for TSP and $\rho=0.5$ for CVRP based on preliminary experiments.
Meanwhile, $\tau_{\min}$ trades off exploration against exploitation---smaller values permit stronger concentration but risk stagnation, while larger values maintain diversity at the expense of slower convergence.
We fix $\tau_{\min} = 1/K$ throughout; a sensitivity analysis appears in Appendix~\ref{app:tuning}.

% 4.2 Training Objective
% ======================================================================
\subsection{Learning Objective and Optimization}
\label{sec:training}
Let $\hat{\pi}_{a,s} = \mathrm{LS}(\pi_{a,s})$ denote the tour produced by ant $a$ at inner iteration $s$ after local search.
We optimize the expected per-iteration post-LS cost as a dense surrogate:
\begin{equation}
J(\theta) = \mathbb{E} \left[ \frac{1}{T} \sum_{h=1}^H \sum_{s=1}^S \frac{1}{m} \sum_{a=1}^m C(\hat{\pi}_{a,s}) \right].
\end{equation}

Although evaluation ultimately cares about the best tour found within a budget, we optimize average cost because doing so produces lower-variance gradients than a sparse best-so-far signal, and empirically the two objectives correlate well: runs with lower average cost also tend to find better final solutions.

We use REINFORCE, differentiating through $\pi_{a,s}$ (pre-LS sampling):
\begin{multline}
\nabla_\theta J(\theta) \approx \frac{1}{T} \sum_{h,s} \frac{1}{m} \sum_{a=1}^m (C(\hat{\pi}_{a,s}) - b_s) \\
\times \nabla_\theta \log \pi_\theta(\pi_{a,s} \mid \mathcal{S}_h),
\end{multline}
where $b_s$ is the batch-mean baseline.
The estimator remains unbiased even with non-differentiable LS, since LS is part of the environment transition~\cite{williams1992simple}.

Under perturbative sampling each ant modifies at most $M$ edges, and the log-probability of its trajectory is simply the sum over realized edge choices.
We compute a per-iteration baseline $b_s = \frac{1}{m}\sum_{a=1}^{m} C(\hat{\pi}_{a,s})$ and define advantage as $A_{a,s} = b_s - C(\hat{\pi}_{a,s})$, so that better-than-average tours receive positive advantage.
For PPO we normalize advantages across the batch: $\hat{A}_{a,s} = (A_{a,s} - \mu_A) / (\sigma_A + \epsilon)$.

We implement a PPO variant that replays trajectories from stored traces to improve sample efficiency without storing the full computational graph.
After collecting trajectories for $S$ inner iterations under $\pi_{\theta_{\text{old}}}$, we perform $K$ optimization epochs using the clipped surrogate:
\begin{multline}
\mathcal{L}^{\text{PPO}}(\theta) = -\mathbb{E}_{a,s}\Big[ \min\big( r_{a,s}(\theta) \hat{A}_{a,s}, \\
\text{clip}(r_{a,s}(\theta), 1{\pm}\epsilon) \hat{A}_{a,s} \big) \Big],
\end{multline}
where $r_{a,s}(\theta) = \pi_\theta(\pi_{a,s} | \mathcal{S}_h) / \pi_{\theta_{\text{old}}}(\pi_{a,s} | \mathcal{S}_h)$, $\epsilon=0.2$, and $\hat{A}_{a,s}$ is the normalized advantage (positive for better-than-average solutions).

Computing the probability ratio $r_{a,s}(\theta)$ requires replaying log-probabilities.
Since the transition kernel~\eqref{eq:held-logits} depends on $\tau^{(h,s)}$, which evolves during rollout, we store pheromone snapshots $\tau^{(h,s)} \in \R^{n \times K}$ and compact integer traces of node choices for each inner iteration.
During the update phase, we reconstruct the policy distribution on the fly.
This storage is discarded after PPO updates for outer step $h$ complete, so peak memory scales as $O(S \cdot n \cdot K)$ rather than $O(H \cdot S \cdot n \cdot K)$.
At $n=10$K with $K=32$ and $S=100$ the pheromone snapshots occupy roughly 128\,MB in fp32, which is manageable on modern GPUs.

Optionally, we anneal the neural prior's influence within each control period, decaying the scale factor from $\gamma$ to $\gamma_{\min}$ across inner iterations so that neural guidance dominates early on and gradually yields to pheromone-driven dynamics.

\begin{algorithm}[t]
\caption{PPO Training for \LGA{} (one outer step)}
\label{alg:train}
\begin{algorithmic}[1]
\STATE Initialize policy $\theta$, optimizer
\FOR{epoch $e = 1, \dots, E$}
    \FOR{step $= 1, \dots, \text{Steps}$}
        \STATE Sample random instance $x$
        \STATE Initialize ACO state; $\tau^{(1,0)} \leftarrow \tau_{\max}$
        \FOR{outer step $h = 1$ to $H$}
            \STATE Build features $\mathcal{S}_h$ from $\tau^{(h,0)}, b^{(h)}$; compute $z_{\theta_{\text{old}}}(\mathcal{S}_h)$
            \STATE \textbf{// Rollout: collect trajectories for this outer step}
            \STATE Initialize storage: $\mathcal{D}_h \leftarrow \emptyset$ \COMMENT{cleared each outer step}
            \FOR{inner step $s = 1$ to $S$}
                \STATE Sample $m$ ants $\pi_{a,s}$ using kernel with $\tau^{(h,s)}$ and held $z_{\theta_{\text{old}}}$
                \STATE Store in $\mathcal{D}_h$: trajectory trace, $\tau^{(h,s)}$, $\log \pi_{\theta_{\text{old}}}$
                \STATE Apply localized LS: $\hat{\pi}_{a,s} \leftarrow \mathrm{LS}(\pi_{a,s})$; compute $C(\hat{\pi}_{a,s})$
                \STATE Update pheromone: $\tau^{(h,s+1)} \leftarrow (1-\rho)\tau^{(h,s)} + \rho \cdot \mathcal{T}$
            \ENDFOR
            \STATE Set $\tau^{(h+1,0)} \leftarrow \tau^{(h,S)}$
            \STATE \textbf{// PPO update using $\mathcal{D}_h$}
            \FOR{PPO epoch $= 1$ to $K$}
                \STATE Recompute $z_\theta(\mathcal{S}_h)$ with current parameters
                \FOR{$(s, \tau^{(h,s)}, \text{trace}, \text{cost}) \in \mathcal{D}_h$}
                    \STATE Replay $\log \pi_\theta$ using stored $\tau^{(h,s)}$ and new $z_\theta$
                    \STATE Compute ratio, advantage, clipped loss as in standard PPO
                \ENDFOR
                \STATE Backprop; optimizer step (clip grad norm 1.0)
            \ENDFOR
            \STATE \textbf{Discard $\mathcal{D}_h$} \COMMENT{memory freed before next outer step}
        \ENDFOR
    \ENDFOR
\ENDFOR
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[t]
\caption{Perturbation-Based Ant Construction}
\label{alg:perturbation}
\begin{algorithmic}[1]
\STATE \textbf{Input:} Incumbent tour $b$, starting node $u_0$, max new-edge steps $M$, shaped kernel $p^\theta$
\STATE $\text{tour} \leftarrow \text{copy}(b)$; $\text{visited}[u_0] \leftarrow \text{true}$; $\text{new\_edge\_steps} \leftarrow 0$
\STATE $\text{checklist} \leftarrow \{u_0\}$; $u \leftarrow u_0$; $\log p \leftarrow 0$
\WHILE{$\text{new\_edge\_steps} < M$ \textbf{and} not all nodes visited}
    \STATE $\mathcal{C} \leftarrow \{v \in \mathcal{N}_K(u) : \neg\text{visited}[v]\}$ \COMMENT{feasible candidates}
    \IF{$|\mathcal{C}| = 0$}
        \STATE $v \leftarrow$ fallback to backup list or greedy
    \ELSIF{$|\mathcal{C}| = 1$}
        \STATE $v \leftarrow$ the single candidate \COMMENT{deterministic, $\log p$ unchanged}
    \ELSE
        \STATE Sample $v \sim p^\theta(\cdot \mid u)$ restricted to $\mathcal{C}$
        \STATE $\log p \leftarrow \log p + \log p^\theta(v \mid u)$
    \ENDIF
    \IF{$(u, v) \notin \text{edges}(b)$} \COMMENT{not adjacent in \emph{incumbent}}
        \STATE $\text{new\_edge\_steps} \leftarrow \text{new\_edge\_steps} + 1$
        \STATE $\text{checklist} \leftarrow \text{checklist} \cup \{u, v, \text{pred}(v)\}$
    \ENDIF
    \STATE \textsc{Relocate}(tour, $u$, $v$) \COMMENT{move $v$ to successor of $u$; changes $\le 3$ edges}
    \STATE $\text{visited}[v] \leftarrow \text{true}$; $u \leftarrow v$
\ENDWHILE
\STATE \textbf{Return:} tour, checklist, $\log p$
\end{algorithmic}
\end{algorithm}

\section{Key Insight: Localized LS for Stable Learning}
\label{sec:perturbative}

We use the local search procedure from~\cite{faco}, restricting moves to neighborhoods induced by modified edges (rather than global 2-opt over the entire tour).
While this restriction reduces computational cost, we find it serves a more critical role: stabilizing policy-gradient training.

When prior neural ACO methods train on post-LS costs, they employ neural-guided LS (NLS) where the learned prior directly weights edges during local search~\cite{deepaco,gfacs}.
This keeps the prior's influence on the post-LS solution differentiable: log-probabilities from ant construction are credited to pre-LS cost, while NLS contributes to post-LS cost.
Our finding is that \emph{spatial locality alone} can substitute for NLS: by confining moves to the neighborhood of sampled edges, localized LS preserves enough of the controller's structure that we can train on post-LS rewards without neural guidance in the LS phase.

\subsection{Localized Local Search}
\label{sec:localized-ls}

Global LS can overwrite most of the edges an ant sampled, decoupling the controller's decisions from the resulting tour cost. Localized LS keeps most sampled edges intact and preserves that connection.
Edge survival and gradient variance measurements (\Cref{sec:ablations}) confirm this.
In practice, the procedure maintains a checklist of nodes incident to the $M$ newly introduced edges and applies restricted 2-opt only to edges that touch the checklist.
This reduces move evaluations from $O(N \cdot K)$ to $O(M \cdot K)$.

Let $\pi$ denote the pre-LS tour sampled by an ant, and $\hat{\pi}=\mathrm{LS}(\pi)$ the post-LS tour that determines the training signal.
Global LS can change $O(N)$ edges of $\hat{\pi}$ from $\pi$ even when the ant only made $O(M)$ targeted modifications.
The cost $C(\hat{\pi})$ then depends weakly on the controller's edge choices, causing high gradient variance.
Localized LS confines modifications to a neighborhood around the ant's changed edges, increasing overlap between sampled actions and the result.
\emph{Edge survival}: $|E(\pi)\cap E(\hat{\pi})|/|E(\pi)|$.

In the ablation (Table~\ref{tab:ablation-ls}) we give both variants the same number of 2-opt iterations.
Global LS gets the same number of node-scanning passes as localized LS (same LS power, different scope).
\emph{Which} edges are examined differs: localized LS focuses on $O(M \cdot K)$ edges incident to the checklist; global LS scans $O(N \cdot K)$ edges with the same iteration budget.

\section{Extension to \CVRP{}}
\label{sec:cvrp}
We extend \LGA{} to the Capacitated Vehicle Routing Problem.

We represent a CVRP solution as a \emph{giant tour}---a permutation of customers---and recover depot insertions via Split~\cite{prins2004}.
Because the search space remains the set of permutations, we can reuse perturbative construction, the candidate graph, and localized 2-opt from the TSP setting, while evaluating the true CVRP objective through Split after each ant.

Improving the Euclidean length of the giant tour does not strictly guarantee an improvement in post-Split CVRP cost, but Split depends strongly on customer order, and better geometric orderings typically reduce inter-customer travel.
Local search therefore uses giant-tour length as a cheap proxy, while policy optimization always receives the true CVRP cost computed by Split.

\subsection{Giant Tour Representation}
The \emph{Giant Tour} representation~\cite{prins2004} encodes a \CVRP{} solution as a permutation of all $n$ customers.
Given a permutation, the optimal route partition (depot insertions) is computed via \texttt{Split}---a DP procedure finding minimum-cost segmentation into capacity-feasible routes.

Split is implemented using prefix sums over route costs, which enables $O(1)$ cost queries during 2-opt (Appendix~\ref{app:split}).

\subsection{Modifications}
For CVRP the graph contains only the $n$ customer nodes; the depot appears implicitly in objective evaluations.\nFeasibility masking is identical to TSP (a Hamiltonian path over customers), and localized 2-opt optimizes the Euclidean length of the giant tour as a cheap proxy while the true CVRP cost is computed once per ant after the LS phase.

\section{Experiments}
\label{sec:experiments}

We evaluate \LGA{} on random Euclidean \TSP{} and \CVRP{} instances across a range of problem sizes.
The experiments investigate whether closed-loop control provides a tangible advantage over open-loop guidance given the additional inference overhead, and identify which components effectively stabilize the training process.

Instance sizes: $N \in \{1\text{K}, 5\text{K}, 10\text{K}, 50\text{K}, 100\text{K}\}$.
Training data is generated on-the-fly (uniform random); validation uses fixed datasets of 128 instances.
Single GPU (NVIDIA RTX 4090).

We distinguish two evaluation regimes.
In the \emph{standard regime} ($N \le 1$K) we compare against DeepACO, GFACS, GTG-ACO, and classical solvers, using LKH-3 or HGS as optimality references.
In the \emph{large-scale regime} ($N \ge 5$K), where those solvers become unreliable, we restrict comparison to scalable methods---vanilla MFACO, open-loop neural, and FocusedACO---and report relative improvement over the strongest baseline under matched wall-clock time.

\subsection{Metrics}
The primary metric is the relative gap to LKH-3 (for TSP) or HGS (for CVRP).
To diagnose training stability we track \emph{edge survival}, the fraction of sampled edges that remain after LS ($|E(\pi)\cap E(\hat{\pi})|/|E(\pi)|$), which measures action--outcome fidelity.
We also report the KL divergence $\mathrm{KL}(p^\theta(\cdot; h, 0) \| q^{(h,0)})$ between the shaped and baseline distributions at the start of each outer step---a proxy for control effort---and \emph{turnover}, the fraction of top-5\% probability edges that change between consecutive refreshes.

\subsection{Baselines}
We compare against several classes of baselines.
Among classical solvers we include \emph{vanilla ACO} (the perturbation-based backend without neural control) and, in the standard regime, \emph{LKH-3} and \emph{HGS} as optimality references.
For neural-ACO methods we consider DeepACO~\cite{deepaco}, GFACS~\cite{gfacs}, and GTG-ACO~\cite{gtgaco}, all of which compute guidance once before search.
Finally, to isolate the benefit of closed-loop control we include an \emph{open-loop baseline}: our own network run once at the start of search using only static features.

\section{Discussion and Limitations}
\LGA{} demonstrates that conditioning on solver state---pheromone distributions and incumbent structure---provides useful signals that static instance features cannot capture.
Our ablations show that localized LS improves edge survival over global LS and reduces gradient variance, enabling stable policy-gradient training.

Several limitations remain.
The GNN encoder adds per-refresh overhead, and RL training is sensitive to hyperparameters---particularly the control period $S$ and the prior annealing schedule.
Moreover, the perturbation-based sampling scheme, while crucial for scalability, limits the solver's reachability compared to global construction; this is an inherited trade-off from the backend~\cite{faco}.

Closed-loop neural control could extend to other combinatorial domains such as job-shop scheduling. Transformer architectures might provide richer context encoding, and curriculum learning strategies that gradually increase problem difficulty during training could improve generalization.

\section{Conclusion}
We have presented \LGA{}, a closed-loop neural controller for Ant Colony Optimization that conditions on pheromone state and incumbent structure, refreshing its guidance periodically throughout the search.
Coupled with a scalable perturbation-based backend and stabilized pheromone dynamics, the controller outperforms both vanilla ACO and open-loop neural guidance on \TSP{} and \CVRP{} under matched wall-clock budgets.
A side benefit of the perturbative design is that localized local search---originally for efficiency---also enables stable policy-gradient training by preserving the connection between the controller's edge choices and the resulting tour quality.
The results suggest that learning to adapt within search, rather than simply initializing it, is a promising direction for neural combinatorial optimization.

\section{Additional Implementation Details}
The encoder is a 12-layer GNN with residual connections and batch normalization (hidden dimension $d=32$).
The decoder is a 3-layer MLP that projects edge embeddings to scalar log-priors.
Input features include 2D node coordinates, $k$-NN distances, pheromone values, and heuristic values (all scalars except coordinates).

\subsection{Complexity Analysis}
The computational cost separates into neural inference and per-iteration ACO operations:

The GNN encoder runs once per outer step and has complexity $O(L \cdot n \cdot K \cdot d)$ for $L=12$ layers, $n$ nodes, $K=32$ candidates, and hidden dimension $d=32$; the edge MLP adds $O(n \cdot K \cdot d)$.
Across $H$ outer steps the total neural cost is $O(H \cdot L \cdot n \cdot K \cdot d)$.

Sampling runs at every inner iteration: each of $m$ ants takes at most $M$ new-edge relocation steps, each costing $O(K)$ for candidate lookup and probability computation, so the per-iteration cost is $O(m \cdot M \cdot K)$ and the total over $T=H{\cdot}S$ iterations is $O(T \cdot m \cdot M \cdot K)$.
Localized local search scans $O(M)$ checklist nodes with $O(K)$ neighbors each, contributing $O(m \cdot M \cdot K)$ per iteration.
Pheromone updates touch only the edges in the best route and cost $O(n)$ per iteration.


With default settings ($H=10$, $S=100$, $L=12$, $d=32$, $m=100$, $M=12$, $K=32$), at $n=10$K:
\begin{itemize}
    \item Neural: $\approx 10 \times 12 \times 10\text{K} \times 32 \times 32 \approx 1.2 \times 10^9$ operations
    \item Sampling: $\approx 1000 \times 100 \times 12 \times 32 \approx 3.8 \times 10^7$ operations per call (but simpler ops)
\end{itemize}
In practice, the GNN runs on GPU while sampling runs on CPU (parallelized via OpenMP), so the neural overhead is 5--15\% of total wall-clock time.

\section{CVRP Split Algorithm Details}
\label{app:split}
\emph{Giant Tour Representation:} 
We map the CVRP to a permutation problem by treating the solution as a single sequence of customers. The optimal cost for a given permutation is found by inserting the depot into the sequence to form valid routes.

\emph{Split Algorithm (Prins 2004):}
Let $P = (c_1, c_2, \dots, c_n)$ be the permutation of customers. We construct a directed acyclic graph $H$ where an edge $(i, j)$ exists if the subsequence $(c_{i+1}, \dots, c_j)$ corresponds to a valid route (load $\le$ Capacity). The weight of edge $(i, j)$ is the cost of that route plus the depot connections. Finding the shortest path from node 0 to node $n$ in $H$ yields the optimal route partition.
Let $V_i$ be the cost of the optimal partition for the first $i$ customers. The Bellman equation is:
\[ V_i = \min_{0 \le j < i} \{ V_j + \text{Cost}(c_{j+1}, \dots, c_i) \} \]
where $\text{Cost}(\cdot)$ includes the depot distances.

\emph{Efficient Local Search:}
To maximize efficiency, our Local Search (2-opt) optimizes the \emph{Euclidean length} of the giant tour as a proxy for the CVRP objective. This allows us to evaluate neighbor moves in $O(1)$ using standard distance deltas. The true CVRP cost is computed only once per ant after the LS phase using an efficient \emph{Linear Split} algorithm ($O(N)$) implemented with a monotonic deque \cite{prins2004}, which avoids the quadratic complexity of the naïve Split.
